# Киоск-режим (Windows, Chrome Kiosk)

Запуск дашборда AI CCTV PPE Detection как отдельного полноэкранного приложения на
Windows-машине с монитором (диспетчерская/пост оператора), а не как вкладки
браузера. Используется штатный **режим киоска Google Chrome** (`chrome --kiosk`):
без адресной строки, вкладок, меню и других элементов управления браузером.
Скрипты — в `kiosk/`.

## Что делают скрипты

| Скрипт | Назначение |
|---|---|
| `kiosk/start_kiosk.ps1` | Открывает Chrome в режиме киоска на нужном URL. Если Chrome закрылся/упал — перезапускает автоматически (пока не поставлен стоп-флаг). Использует отдельный профиль Chrome (`%LOCALAPPDATA%\PPEKiosk\ChromeProfile`), поэтому вход в систему (JWT) не сбрасывается при перезапуске. |
| `kiosk/install_autostart.ps1` | Регистрирует задачу планировщика Windows: `start_kiosk.ps1` запускается автоматически при входе пользователя. Требует прав администратора. |
| `kiosk/uninstall_autostart.ps1` | Удаляет задачу автозапуска. |
| `kiosk/stop_kiosk.ps1` | Штатно останавливает киоск (стоп-флаг + закрытие процесса Chrome киоска), без остановки задачи автозапуска. |

## Быстрый старт (ручной запуск, проверить перед автозапуском)

```powershell
cd kiosk
.\start_kiosk.ps1                              # http://localhost:8000 — бэкенд на этой же машине
.\start_kiosk.ps1 -Url "http://192.168.0.85"   # если фронт вынесен на отдельный сервер (см. deploy.env)
```

Выйти из полноэкранного режима вручную во время проверки — `Alt+F4` (Chrome
перезапустится через ~2 сек, это ожидаемо) либо `.\stop_kiosk.ps1` из другого
PowerShell (полная остановка).

## Постоянная установка (выделенный киоск-терминал)

1. **Создать отдельную локальную учётную запись Windows** для киоска (не
   администратора), например `ppekiosk`, с автоматическим входом:
   ```
   Панель управления → Учётные записи → netplwiz →
   снять галочку «Требовать ввод имени пользователя и пароля» → выбрать ppekiosk
   ```
   Либо через реестр (`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon`):
   `AutoAdminLogon=1`, `DefaultUserName`, `DefaultPassword`, `DefaultDomainName`.
2. Убедиться, что бэкенд (`docker compose --profile gpu up -d` или
   `python app.py`) поднимается автоматически при загрузке машины —
   `start_kiosk.ps1` ждёт `/health` до `-WaitForBackendSec` (по умолчанию 120с),
   но не бесконечно.
3. Отключить экранную заставку, спящий режим и автообновления Windows с
   принудительной перезагрузкой (Групповые политики / `powercfg`) — иначе
   терминал уйдёт в сон или перезагрузится посреди смены.
4. Установить Google Chrome под учёткой `ppekiosk` (или системно).
5. Скопировать репозиторий (или хотя бы папку `kiosk/`) на терминал.
6. Из PowerShell **от имени администратора**, под учёткой `ppekiosk` (или
   указав `-User`):
   ```powershell
   cd kiosk
   .\install_autostart.ps1 -User "$env:COMPUTERNAME\ppekiosk" -Url "http://localhost:8000"
   ```
7. Перезагрузить машину — после автологина `ppekiosk` Chrome должен открыться
   в киоске автоматически.

## Как остановить / выйти (для администратора)

Уровень блокировки — только Chrome (см. ниже про более глубокую блокировку),
поэтому у администратора всегда есть штатный путь остановить киоск:

- Локально под учёткой киоска: `kiosk\stop_kiosk.ps1` — закроет Chrome и не даст
  ему перезапуститься, задача автозапуска при этом остаётся зарегистрированной
  (сработает при следующем входе).
- Полностью снять автозапуск: `kiosk\uninstall_autostart.ps1` (нужны права
  администратора).
- Экстренно: `Ctrl+Alt+Del` → «Сменить пользователя» → войти в другую
  (администраторскую) учётную запись, если она есть на машине.

## Что НЕ входит в этот уровень блокировки

Реализован только киоск-режим Chrome (флаги `--kiosk`, `--noerrdialogs`,
изолированный профиль, автоперезапуск при закрытии). Это не блокирует:
- переключение окон (`Alt+Tab`), меню «Пуск», диспетчер задач — оператор
  технически может свернуть Chrome или завершить процесс через диспетчер задач
  (правда, `start_kiosk.ps1` тут же откроет его заново, если процесс PowerShell
  ещё жив);
- сочетания клавиш Windows.

Для более глубокой блокировки ОС (запрет Alt+Tab/Win, скрытие панели задач,
запрет диспетчера задач) — штатный инструмент Windows **Assigned Access
(«Назначенный доступ» / Kiosk mode в Параметры → Учётные записи → Семья и
другие пользователи)**, либо групповые политики (`gpedit.msc`:
`Отключить диспетчер задач`, `Удалить меню «Выполнить»` и т.п.). Это отдельная
настройка ОС поверх `kiosk/`, в репозитории не автоматизирована.

## Полезные флаги Chrome, использованные в скрипте

- `--kiosk <url>` — полноэкранный режим без UI браузера.
- `--user-data-dir=<путь>` — отдельный профиль, не трогает обычный Chrome
  пользователя; сохраняет вход (JWT) между перезапусками.
- `--noerrdialogs`, `--disable-session-crashed-bubble` — не показывать диалоги
  об ошибках/восстановлении сессии (мешают киоску).
- `--autoplay-policy=no-user-gesture-required` — голосовые предупреждения
  (`/api/voice_alert_audio`, см. CLAUDE.md §2.4.1) проигрываются через
  `<audio>` без клика пользователя; без этого флага Chrome блокирует автовоспроизведение звука.
- `--disable-pinch`, `--overscroll-history-navigation=0` — не реагировать на
  жесты (если сенсорный монитор).
